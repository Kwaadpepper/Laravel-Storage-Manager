Laravel Storage Manager

A modern, embeddable, multi-storage file manager for Laravel applications. Clean UI, fast workflows, and multi-driver support.

View on GitHub Get Started

📖 Overview

Laravel Storage Manager is an all-in-one file management solution designed to embed directly into Laravel applications. Built with a modern Vue 3 (Composition API), Tailwind CSS v4, and DaisyUI 5 frontend, it delivers an intuitive user experience while supporting complex storage backends out-of-the-box.

✨ Key Features

📁 Multi-Storage Drivers

Seamlessly manage files across Local filesystem, Amazon S3, MinIO, Cloudflare R2, FTP, SFTP, and custom Flysystem adapters.

⚡ Resumable Chunked Uploads

Reliable multi-part upload pipeline with client-side hashing, atomic session locking, and customizable conflict handling.

📝 Rich Text & Form Integration

Plug-and-play integrations for CKEditor 5, CKEditor 4, TinyMCE 5/6, Tiptap, and standard standalone form file pickers.

🎬 Media Streaming & Viewers

Range-request streaming for audio & video (HTTP 206), inline PDF viewing, text/code editor with syntax highlighting, and Cropper.js image editing.

🗑️ Trash & Soft Deletes

Safe file operations with soft delete functionality, simple trash restoration, configurable auto-pruning, or permanent purges.

📦 Archives & Batch Operations

Create and safely unpack ZIP archives with zip-slip protection. Perform bulk rename, copy, move, and recursive operations.

🚀 Quick Start

1. Install via Composer:

composer require kwaadpepper/laravel-storage-manager

2. Publish assets and configuration:

# Publish frontend assets
php artisan vendor:publish --tag=storage-manager:assets

# Publish configuration (optional)
php artisan vendor:publish --tag=storage-manager:config

3. Access the manager:

// Visit the default route in your browser:
http://your-app.test/storage-manager
